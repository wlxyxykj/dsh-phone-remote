安全须知

  1. 链接里的口令就是全部凭证：拿到它的人可以在你的电脑上让 Agent 执行操作。别把链接发到群里或截图发出去。
  2. 这台电脑有公网 IP 时，8790 端口对全网可见。默认的「口令优先」已经够用：没带口令的扫描者进不来，而你的手机无论换到哪个网络都能连。想更严一点再开「严格模式」。
  3. 手机换网络后如果显示「此设备未授权」，说明那次请求没带口令——用面板上的链接/二维码（里面含口令）访问即可，不用在这里点允许。
  4. 公共 Wi-Fi 下建议用完就在配置里设 enabled: false，或点上面的“重置口令”。
  5. 默认给手机新建的会话下发 approvalPolicy: never，即不再逐条询问授权；可在插件配置里改成 ask。
